# 🚀 ML Learning Journey

Day-to-day progress log of my journey through **Python, Data Analysis, Statistics, Machine Learning, Deep Learning, PyTorch, Computer Vision, and DSA**. Each folder/notebook corresponds to a day (or a couple of days) of study, with hands-on code, notes, and experiments.

## 📌 About

This repository is a personal learning log — a chronological record of concepts learned and implemented while building a foundation in ML/DL. Content ranges from Python fundamentals to deep learning with PyTorch, with detours into SQL, statistics, and data structures & algorithms.
